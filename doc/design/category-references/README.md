Material recibido del usuario para estas categorías. No se proporcionó autoría

no declararlo dominio público ni asignarle CC BY-SA por inferencia.

Las copias WebP de Android conservan las dimensiones de los PNG. Las tarjetas
usan una proporción de 1,65:1 y recortan en torno a la torre y fachada, las
terrazas, el mirador y la bahía, y el plato, respectivamente. La imagen ocupa
su propio espacio sobre el nombre de la categoría.
